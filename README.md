## 💡 Overview

Poket Vet & Pet Shop brings pet adoption options, essential foods, accessories, and clinical services together under one roof. 

### Key Features Included in This Demo:
* **Dynamic Tab Navigation**: Seamless switching between **Home**, **Shop**, **Services**, **Veterinary**, and **About Me** views.
* **Context-Aware Category Badges**: Category pills automatically update based on the active main navigation view.
* **Expanded Catalog**: Features diverse dog and cat breeds, exotic birds, aquarium fishes, premium foods, and health care services.
* **Interactive Cart & Modals**: Functional shopping cart overlay with live pricing updates, login/register modals, and demo admin controls.
* **Pet Owner Resource Hub**: Visual "About Me" section highlighting how the platform simplifies everyday pet care.

## 🛠️ Built With

* **CSS3** – Custom styling with modern grid/flexbox layouts and responsive elements
